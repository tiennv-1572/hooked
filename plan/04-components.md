## Ghi chú cho implementation

- **Recurring nhưng không phải library component**: Navigation desktop và Footer được copy thành frame riêng trên từng trang (không phải instance) → build 1 component, đừng bám từng frame.
- **Biến thể "Interactive" / "Hover visual"** trên mọi screen chỉ là wrapper prototype → dùng CSS `:hover` / `:focus-visible`.
- **Fonts**: Manrope (UI), Inter (Blog carousel). Handoff ghi rõ layer intro Home `145:16` dùng **Young Display Bold** — font không có trong renderer Figma, cần file font gốc hoặc mapping thay thế.
- Text trên poster project (khung cam graffiti, chữ "event production…", tên, ngày) **được baked vào ảnh** → export ảnh, không dựng bằng text.
- Một số component library chứa nội dung placeholder (`TÊN KHÓA HỌC`, `Đang cập nhật.`, `Tên dự án 1`, `Tên bài viết`) → chỉ lấy style, nội dung từ data.
